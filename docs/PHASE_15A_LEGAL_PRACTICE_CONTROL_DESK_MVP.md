# Phase 15A Legal Practice Control Desk MVP

## Objective
Create the first business-useful MVP milestone for Litigation 360 / LEOS without changing the approved localhost:5173 appearance.

## Non-Negotiable Visual Rule
The current localhost:5173 appearance is the approved baseline.
No redesign is allowed.
No new UI system is allowed.
No new navigation style is allowed.
No new color system is allowed.
No broad CSS changes are allowed.

## Implementation Rule
All new MVP content must use existing page structure, existing cards, existing tables, existing buttons, existing spacing, and existing classes wherever possible.

## MVP Feature
Add a Legal Practice Control Desk / Today Overview using sample data only.

## Required Content
- Urgent matters
- Upcoming deadlines
- Missing documents
- Pending client instructions
- Overdue tasks
- Recently updated matters

## Data Rule
Use sample/demo data only.
Do not enter real client data yet.

## Blocked Scope
- Backend changes
- Database changes
- Auth/RBAC changes
- API changes
- Dependency changes
- New design system
- New dashboard redesign
- Production deployment

## Acceptance Checklist
- Existing localhost:5173 appearance remains visually consistent.
- Existing navigation remains unchanged.
- Existing styling remains unchanged.
- Practice overview is visible.
- Father can understand urgent work within 30 seconds.
- Build passes.
- Git diff is small and reviewable.

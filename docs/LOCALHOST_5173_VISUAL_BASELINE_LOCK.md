# Localhost 5173 Visual Baseline Lock

## Status
The current localhost:5173 appearance is the approved visual baseline.

## Non-Negotiable Rule
No new UI may be created.
No redesign may be introduced.
No alternate visual system may be introduced.
No broad appearance changes may be made.

## Development Rule
All future features, corrections, and MVP work must be developed from the current localhost:5173 appearance.

## Allowed Changes
- Functional fixes that preserve the current appearance.
- Data wiring that does not change the layout.
- Text corrections that do not alter the visual structure.
- Bug fixes.
- Build fixes.
- Small alignment fixes only where something is visibly broken.

## Blocked Changes
- New dashboard design.
- New layout system.
- New color system.
- New navigation style.
- New page shell.
- Replacing the current localhost appearance.
- Reworking UI for preference or polish.

## Practical Meaning
The current UI is the foundation. Do not restart, redesign, or create another interface.

## Reason
The project is under urgent solo-developer delivery pressure and must prioritize usable legal-business value over visual redesign.
